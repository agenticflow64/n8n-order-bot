## Как использовать в демо

- В веб-эмуляторе чата (`http://localhost:8000/chat`) первые пять примеров доступны как чипсы-кнопки под полем ввода.
- Скрипт замера точности по всему набору: `python3 scripts/measure_accuracy.py` (реальный API OpenRouter, нужен `.env`).
