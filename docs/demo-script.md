# Сценарий демо (≤ 2 минут)

Подготовка (заранее, до записи): `docker compose up -d --build` + `./workflows/import-workflow.sh`.

**Хронометраж: ~110 секунд.**

Примечание: модель `nvidia/nemotron-3.5-lightning:free` даёт 100% точности, но отвечает ~17 с — во время «бот печатает…» комментируйте схему. Для более шустрой записи можно временно поставить `OPENROUTER_MODEL=nvidia/nemotron-3-ultra-550b-a55b:free` (медиана ~9 с, точность 10/12) и перезапустить стек.

| Время | Экран | Действия / что говорить |
|-------|-------|-------------------------|
| 0:00–0:15 | n8n UI, вкладка workflow | Открыть workflow «Order Bot — приём заказов». Показать схему слева направо: два канала приёма (TG-опрос getUpdates + эмулятор) → нормализация → LLM → разбор → Switch с тремя ветками (успех / ретрай / оператор) → backend → финальный Switch ответа. |
| 0:15–0:35 | n8n UI, Executions | Открыть пару прошлых выполнений: зелёные ноды, внутри «LLM: Извлечь заказ» — реально пришедший JSON со `service_type`, `urgency`, `contact`. Показать одно выполнение с веткой ретрая/эскалации. |
| 0:35–1:05 | Эмулятор чата `localhost:8000/chat` | «Эмулятор — второй канал: шлёт вебхук в тот же workflow, что и живой Telegram». Отправить сэмпл с чипса («стрижку собаке… срочно!!»). Показать: бот печатает → пришла сводка «Заказ принят, №N» с услугой, кличкой, срочностью. Нажать «Подтвердить заказ». |
| 1:05–1:25 | Админка `localhost:8000` | Заказ уже в таблице, статусы цветными точками, строка счётчиков сверху. Перевести заказ в «в работе». Отправить из эмулятора мусорный текст («а вы вообще чё за контора??») → в админке появляется «Ручная обработка», клиенту — «оператор подключится». |
| 1:25–1:50 | Терминал | Показать healthchecks: `docker compose ps` (healthy). Проговорить: e2e-тесты — `14 passed`, точность извлечения на 12 сэмплах и время ответа LLM — в README кейса. |

## Кадры для скриншотов

1. Вся схема workflow с под горящими (выполненными) нодами.
2. Input/Output ноды «LLM: Извлечь заказ» (сырой текст → чистый JSON).
3. Чат эмулятора: сообщение клиента + сводка + кнопка подтверждения.
4. Админка: таблица заказов, фильтр по статусу, счётчики.
